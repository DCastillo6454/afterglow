# AFTERGLOW — Sunset to Midnight

A responsive website for **AFTERGLOW**, a fictional desert music festival concept, headlined by VYRA NOR.

**The site lives in [`output/`](output/).** See [`output/README.md`](output/README.md) to run, test and rebuild it.

```sh
cd output
npm install
npm run serve      # http://localhost:5173
npm test           # in a second terminal
```

## Repository layout

| Folder | Contents |
| --- | --- |
| `output/` | The website: HTML, CSS, JS, generated images, fonts and build/test scripts |
| `Images/`, `Marketing/`, `Merchandise/`, `Ticketing + Maps/`, `Brand World/`, `Website UI/` | Original brand and campaign asset masters. The image build reads these |
| `afterglow-scenes/` | Original Experience scene renders and their handoff notes |
| `CLAUDE-HANDOFF.md`, `ASSET-MANIFEST.json` | Asset collection brief and manifest |

This is a concept project. Dates, venue, pricing and set times are not real. The grounds, vendors and partners are fictional, and the checkout and mailing-list flows are demos that send no data.

The display font, Chakra Petch, is used under the SIL Open Font License (`output/assets/fonts/OFL.txt`).
