Vendor and sponsor sheets are concept raster artwork. The invented names establish fictional festival brands; no real partnerships are claimed. Confirmation illustrations do not implement purchase or signup behavior.

## Overlays

All four overlay PNGs contain true transparent and partially transparent pixels, checked on a 16-pixel grid. Preserve their alpha channel when exporting. Place them as decorative layers above artwork, below interactive content, with pointer-events: none and an empty alt attribute. Adjust opacity for text contrast. Normal alpha blending is available; screen blending is an optional visual treatment on dark backgrounds.
